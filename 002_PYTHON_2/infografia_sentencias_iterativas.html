Sentencias iterativas en Python

Infografía explicada como profesor de programación

Idea central: los bucles permiten automatizar tareas repetitivas. La clave no es solo memorizar `while` o `for`, sino entender qué controla la repetición: una condición, una colección o una secuencia numérica.

Bloque 1

Qué son y por qué importan

Definición

  • Permiten repetir un bloque de instrucciones varias veces.
  • Evitan escribir el mismo código de forma manual.
  • Son esenciales al trabajar con listas, tuplas, diccionarios o grandes conjuntos de datos.

Ventajas

  • Eficiencia: menos repetición manual.
  • Mantenimiento: código más limpio y menos redundante.
  • Flexibilidad: se adapta a distintos problemas.
  • Optimización: simplifica algoritmos complejos.
Bloque 2

While vs For

`while`

  • Repite mientras una condición sea verdadera.
  • Conviene cuando no conoces el número exacto de repeticiones.
  • Ejemplos: validar una entrada, monitorear un proceso, esperar un evento.
  • Riesgo: bucle infinito si no actualizas la variable de control.

`for`

  • Recorre automáticamente elementos de una colección.
  • Conviene cuando iteras listas, tuplas, diccionarios o secuencias.
  • No exige manejar manualmente el avance en los casos normales.
  • Es más legible y reduce errores comunes.

Regla práctica: si la repetición depende de una condición, piensa en `while`; si depende de elementos o repeticiones contadas, piensa en `for`.

Bloque 3

Range, listas y diccionarios

🔢

`range()`

Genera secuencias numéricas. Se usa como `range(fin)`, `range(inicio, fin)` o `range(inicio, fin, paso)`.

📋

Listas

Con `for` puedes recorrer cada elemento, transformarlo, filtrarlo o modificarlo por índice.

🗂️

Diccionarios

Se recorren con `items()`, `keys()` y `values()`. Lo más común es usar `items()` para clave y valor.

Detalle importante: el límite superior de `range()` no se incluye.
Precaución: no conviene modificar un diccionario directamente mientras lo recorres.
Bloque 4

Herramientas avanzadas

Control del flujo

  • break: corta el bucle de inmediato.
  • continue: salta a la siguiente iteración.
  • Bucles anidados: útiles, pero más costosos si se abusa de ellos.

Recorrido inteligente

  • enumerate(): entrega índice y valor.
  • zip(): recorre varias colecciones a la vez.
  • Comprensiones: transforman y filtran con menos código.
  • Generadores: producen valores sobre la marcha con mejor uso de memoria.
Bloque 5

Optimización, depuración y patrones

Optimizar

Mover cálculos costosos fuera del bucle, evitar anidados innecesarios y usar comprensiones cuando ayuden a simplificar.

Depurar

Imprimir variables clave, limitar iteraciones en pruebas y revisar siempre la condición de salida.

Patrones

Acumulación, filtrado y búsqueda son tres formas clásicas de pensar un problema con bucles.

Bloque 6

Ejercicios aplicados

Inventario

  • Lista de diccionarios con nombre, stock y precio.
  • `for` para revisar productos y detectar stock bajo.
  • Comprensión para crear lista de reposición.
  • `while` para simular ingreso de productos hasta escribir salir.

Análisis académico

  • `zip()` para unir nombres y notas.
  • `enumerate()` para ubicar la nota más baja.
  • Comprensión para aprobados y alumnos que deben rendir.
  • `break` para cortar si aparece una nota perfecta.

Sentido pedagógico: ambos ejercicios obligan a elegir correctamente la estructura iterativa según el problema, y no solo a repetir sintaxis de memoria.

👨‍🏫

Qué debes dominar para el examen

✅ Elegir entre `while` y `for` según la lógica del problema.

✅ Usar `range()` para repeticiones controladas e índices.

✅ Recorrer listas y diccionarios con claridad.

✅ Aplicar `break`, `continue`, `enumerate()` y `zip()` cuando corresponda.

✅ Construir comprensiones para filtrar y transformar datos.

✅ Pensar primero la lógica de repetición y luego escribir el código.
