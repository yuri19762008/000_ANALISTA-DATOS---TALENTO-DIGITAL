# 📊 Portafolio de Analista de Datos

Bienvenido a mi repositorio de formación y proyectos en análisis de datos. Este espacio reúne mi progreso, prácticas y proyectos desarrollados durante mi proceso de aprendizaje como Data Analyst.

---

## 🚀 Objetivo

Este repositorio tiene como objetivo:

- Consolidar conocimientos en análisis de datos
- Aplicar técnicas de limpieza, transformación y visualización
- Desarrollar proyectos prácticos basados en datos reales
- Construir un portafolio profesional

---

## 🧠 Tecnologías y herramientas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Estructura del repositorio

El contenido está organizado en módulos:

- **Módulo 1 - 11**: Contenido progresivo del bootcamp
  - Fundamentos de datos
  - Limpieza de datos
  - Análisis exploratorio (EDA)
  - Visualización
  - Estadística
  - Modelos básicos

- **EJEMPLOS**: Casos prácticos y ejercicios adicionales
- **Bootcamp-main**: Material base del programa
- **automatico**: Scripts y automatizaciones
