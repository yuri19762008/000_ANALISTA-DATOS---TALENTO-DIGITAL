Fundamento conceptual

¿Qué es MLlib y por qué importa?

MLlib es la biblioteca de machine learning de Apache Spark y está pensada para construir, entrenar y evaluar modelos de forma distribuida, integrada con Spark SQL y otros componentes del ecosistema.

Escalabilidad horizontal

Procesa datasets que superan la memoria de una sola máquina y distribuye el trabajo en clústeres.

Integración nativa

Convive con Spark SQL, Streaming y el flujo completo de datos sin salir del ecosistema Spark.

API moderna

La evolución desde RDD hacia DataFrames mejoró rendimiento, expresividad y facilidad de uso.

Uso práctico

Incluye clasificación, regresión, clustering, reducción de dimensionalidad y evaluación.

Base del modelado

Estructuras de datos clave

En MLlib, los DataFrames organizan los datos de entrada y salida, mientras que los vectores y matrices permiten representar características numéricas de manera eficiente.

Estructura Uso principal Idea clave
DataFrame Entrada, transformación y salida Tabla distribuida por columnas, base de la API moderna
DenseVector Features numéricas con muchos valores no nulos Guarda todos los valores del vector
SparseVector Datos con muchos ceros Guarda solo índices y valores no nulos para ahorrar memoria
Matriz PCA, SVD y factorización Representación bidimensional para operaciones avanzadas
Pipeline Encadenamiento de etapas Hace reproducible y ordenado el flujo de ML

Algoritmos que aparecen en la ruta del módulo

La guía trabaja con clasificación, regresión, clustering y reducción de dimensionalidad, siempre pensados para ejecutarse sobre datos distribuidos.

Supervisados
  • Regresión logística para clasificación binaria y multiclase
  • Árboles de decisión, Random Forest y Gradient-Boosted Trees
  • Regresión lineal y regresores basados en árboles
  • Naive Bayes y SVM para escenarios de clasificación
No supervisados
  • K-Means, Gaussian Mixture Model y Bisecting K-Means
  • PCA y SVD para reducción de dimensionalidad
  • ALS para filtrado colaborativo y recomendación
  • Power Iteration Clustering para agrupamiento basado en grafos
Flujo reproducible

Cómo se arma un pipeline en MLlib

El material explica que un pipeline encadena transformadores y estimadores. Así, la preparación, el entrenamiento, la predicción y la evaluación quedan en una misma secuencia lógica y repetible.

1. Ingesta y limpieza
DataFrame con columnas de entrada bien definidas.
2. Ingeniería de variables
StringIndexer, OneHotEncoder, VectorAssembler, escalado o normalización.
3. Modelo
Estimator como LogisticRegression, LinearRegression o KMeans.
4. Predicción
El modelo entrenado actúa como Transformer sobre nuevos datos.
5. Evaluación
Métricas como F1, AUC, RMSE o MAE según el problema.

Ejemplos visuales de código

Aquí se agregó una sección más práctica para estudiar: un ejemplo supervisado con regresión logística y un ejemplo no supervisado con K-Means y PCA.

Ejemplo 1 · Clasificación con LogisticRegression
from pyspark.sql import SparkSession
from pyspark.ml.feature import VectorAssembler
from pyspark.ml.classification import LogisticRegression
from pyspark.ml import Pipeline
from pyspark.ml.evaluation import BinaryClassificationEvaluator

spark = SparkSession.builder.appName("demo-mllib").getOrCreate()

df = spark.createDataFrame([
    (0, 18.0, 1.0, 0.0),
    (1, 35.0, 4.0, 1.0),
    (2, 47.0, 7.0, 1.0),
    (3, 23.0, 2.0, 0.0)
], ["id", "edad", "compras", "label"])

assembler = VectorAssembler(
    inputCols=["edad", "compras"],
    outputCol="features"
)

lr = LogisticRegression(
    featuresCol="features",
    labelCol="label",
    maxIter=10,
    regParam=0.01
)

pipeline = Pipeline(stages=[assembler, lr])
model = pipeline.fit(df)
pred = model.transform(df)

evaluator = BinaryClassificationEvaluator(labelCol="label")
auc = evaluator.evaluate(pred)
Qué está pasando en este flujo
Se crea una SparkSession para trabajar con MLlib desde PySpark.
Las columnas numéricas se unen en features con VectorAssembler.
Se define un modelo de LogisticRegression para clasificación.
Todo se organiza en un Pipeline, que luego se ajusta con fit().
Finalmente, las predicciones se evalúan con un BinaryClassificationEvaluator.
Ejemplo 2 · K-Means + PCA
from pyspark.ml.clustering import KMeans
from pyspark.ml.feature import VectorAssembler, PCA
from pyspark.ml import Pipeline

ventas = spark.createDataFrame([
    (1, 120.0, 15.0, 2.0),
    (2, 130.0, 18.0, 3.0),
    (3, 400.0, 55.0, 8.0),
    (4, 390.0, 52.0, 7.0)
], ["id", "monto", "frecuencia", "devoluciones"])

assembler = VectorAssembler(
    inputCols=["monto", "frecuencia", "devoluciones"],
    outputCol="features"
)

pca = PCA(k=2, inputCol="features", outputCol="pca_features")

kmeans = KMeans(
    k=2,
    seed=42,
    featuresCol="pca_features",
    predictionCol="cluster"
)

pipeline = Pipeline(stages=[assembler, pca, kmeans])
modelo = pipeline.fit(ventas)
resultado = modelo.transform(ventas)
resultado.select("id", "pca_features", "cluster").show()

Primero se ensamblan variables, luego PCA reduce dimensionalidad y finalmente K-Means agrupa observaciones parecidas. Esta secuencia representa muy bien el enfoque modular de MLlib.
