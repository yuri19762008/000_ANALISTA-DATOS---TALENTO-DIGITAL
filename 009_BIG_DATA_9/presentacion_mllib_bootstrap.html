Problema

Por qué se necesita machine learning escalable

El documento explica que el crecimiento exponencial de datos vuelve insuficientes los enfoques tradicionales de análisis y modelado cuando se intenta trabajar a gran escala.

Limitación 1. Una sola máquina no siempre puede alojar todos los datos necesarios para entrenar un modelo.
Limitación 2. El tiempo de entrenamiento y evaluación crece cuando no existe paralelismo ni distribución.
Respuesta. Spark MLlib aprovecha clústeres para ejecutar procesos de forma distribuida.

Biblioteca central

Qué es MLlib

1

Definición

MLlib es la biblioteca de Machine Learning de Apache Spark, diseñada para construir, entrenar y evaluar modelos de forma distribuida.

2

Integración

Se integra con Spark SQL, Spark Streaming y otros componentes del ecosistema Spark.

3

Alcance

Permite resolver tareas de clasificación, regresión, clustering y reducción de dimensionalidad.

4

Escala

Está pensado para datasets que ya no caben en la memoria de una sola máquina.

Estructuras de datos

Componentes principales en MLlib

Estructura Rol Uso principal
DataFrame Colección distribuida organizada en columnas Entrada, transformación y almacenamiento de resultados.
DenseVector Guarda todos los valores Conviene cuando la mayoría de los elementos no son cero.
SparseVector Guarda índices y valores no nulos Optimiza memoria cuando predominan los ceros.
Matrix Representación bidimensional Útil en SVD y factorización matricial.
Pipeline Cadena etapas del flujo Facilita automatización y reproducibilidad.

Idea para explicar

Estas estructuras no son accesorios: son la base sobre la que se construyen y ejecutan los algoritmos de MLlib.

Dense guarda todo; Sparse guarda solo lo relevante.

Algoritmos

Supervisado y no supervisado

Supervisado

Trabaja con etiquetas

  • Logistic Regression para clasificación binaria y multiclase.
  • Linear Regression para predicción de valores continuos.
  • Árboles, Random Forest y Gradient-Boosted Trees amplían el catálogo.
No supervisado

Descubre patrones sin etiquetas

  • K-Means agrupa observaciones por similitud.
  • Gaussian Mixture Model modela clústeres probabilísticos.
  • PCA reduce dimensión conservando la mayor información posible.

Métricas del modelo

AUC

Muy usada en clasificación binaria.

F1

Combina precision y recall.

RMSE

Mide error típico en regresión.

MAE

Error absoluto medio con interpretación directa.
