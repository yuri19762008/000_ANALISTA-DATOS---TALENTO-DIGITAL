¿Por qué ML escalable?

  • Los datos masivos superan la capacidad de una sola máquina
  • Se necesita paralelismo y distribución
  • MLlib aprovecha clústeres de Spark
  • Permite trabajar con millones de registros

Qué es MLlib

  • Biblioteca de machine learning de Apache Spark
  • Integra clasificación, regresión y clustering
  • Se conecta con Spark SQL y otros módulos
  • Está diseñada para escala real

Estructuras de datos

  • DataFrame como estructura principal
  • DenseVector para features densas
  • SparseVector para ahorrar memoria
  • Matrix y Pipeline para flujos avanzados

Supervisado

  • Usa datos etiquetados
  • Ejemplos: Logistic Regression y Linear Regression
  • También árboles y ensambles
  • Objetivo: predecir clases o valores

No supervisado

  • No requiere etiquetas
  • K-Means agrupa por similitud
  • GMM modela clústeres probabilísticos
  • PCA reduce dimensión y ruido

Flujo con MLlib

  • Preparar datos y construir features
  • Dividir train/test
  • Entrenar y predecir
  • Evaluar con métricas adecuadas

Pipelines y evaluación

  • Pipeline automatiza etapas
  • Métricas: AUC, F1, RMSE, MAE
  • Clustering: Silhouette Score
  • Validación cruzada y Grid Search mejoran resultados

Cierre

  • MLlib une machine learning y Big Data
  • Escala mejor que enfoques locales
  • DataFrames, vectores y pipelines son claves
  • Base sólida para proyectos de datos masivos
